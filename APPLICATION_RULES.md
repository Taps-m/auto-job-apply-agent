# Application rules — V 0.4.4

- Search daily by default, with a manual Run now option.
- Apply when the computed profile match score is **at least 80%**, including exactly 80%.
- No user-defined daily application cap. Portal-imposed limits still apply.
- Existing salary, role, seniority, location and exclusion criteria remain applicable.
- Submit only through supported, permitted routes with known required answers; ask the user for missing facts.
- Skip duplicate applications and retain confirmation of successful submission.
- Generate application and response reports weekly.

These are saved requirements for the application connector. Automatic discovery, scheduling and submission are not operational yet. A profile match score is an estimate, not an interview probability.
